本表的假设行属于当前项目实例（含具体站名/实验线），换项目时归档重开；表结构与状态流转纪律属于技能逻辑，保持不变。

**引擎包里的这一份是格式样例，只读。** 运行时的登记表是 `<workdir>/references/hypotheses.md`：
照本表的结构新建，只写本次项目的假设行。任何 playbook、任何卡片都不得往引擎包这一份里追加行——
它随技能分发、被所有项目共享，写进去等于把上一个项目的假设塞给下一个项目。

## 怎么用这张表

- **每条假设的字段含义**：
  - **ID**：稳定编号，FINDINGS.md 与 ANALYSIS.md 用它交叉引用。
  - **机制**：从架构推出的因果猜测（从 models.md 搬运，不是本表新造）。
  - **可判别预测**：如果假设为真，数据上**应当看到什么**、以及**不应看到什么**——能被证伪才算数。
  - **验证手段**：用哪张图 / 哪个统计量来检验。
  - **状态**：`预注册`（写了预测还没验）/ `证实` / `推翻` / `证据不足`（样本量或信噪比不够、下不了定论）。
  - **证据链接**：证实或推翻时，指向 ANALYSIS.md 的小节或图文件，并注明日期。
- **状态怎么流转（纪律）**：
  1. 分析前先读本表，认领相关条目（把要验的 `预注册` 挑出来）。
  2. 看图后按结果改状态；**证实和推翻都要写证据链接**，`证据不足` 要写清楚是样本量问题还是信噪比问题。
  3. 结论进 FINDINGS.md 时带上 ID，例如： "（H-CHRONOS-1 证实）M1/M3/M4 在 2025-06 同步变差而 M2 稳……"。
  4. 表里没有能对应当前发现的条目 → **先在此新增一条 `预注册`**（写清可判别预测），再去看图验证，不要跳过登记直接下结论。
- **和另外两道门的分工**：本表管"预测是否被数据支持"；稳健性门槛管"差异是不是噪声"；反驳门管"有没有别的解释"。三者都过，结论才升级为 `证实` 进 FINDINGS.md。

### H-M2-6 — MLP 无时序平滑先验 → 时效曲线毛刺、继承气象预报高频误差
- **机制**：M2 是 MLP，全连接结构下"时间信息消失"（没有时序归纳偏置），192 个输出点之间没有连续性约束；且它的输出近似气象预报形状的直接映射（源：models.md M2 第 45、68 行）。
- **可判别预测**：图#5 时效曲线上 M2 的逐步 RMSE 呈**高频毛刺**（相邻步误差不连续），而有时序结构的 M1/M3/M4 曲线光滑；M2 的毛刺继承自气象预报本身的高频误差。反例（能证伪、也能区分数据噪声）：若**所有模型都毛** → 是昼夜包络（周期≈96 步）漏入的采样噪声，与本条无关；毛刺周期≈32 步 → 撞上 M2 的 patch_size=32 边界（支持本条），≈96 步 → 昼夜包络（作废本条）。
- **验证手段**：图#5（分模型比曲线光滑度）+ 对 M2 逐步 RMSE 做 FFT/自相关看主周期。

### H-M2-2 — 九路"先嵌入再求和"保留 NWP 离散度 → 多云/突变天特长

## F. 日内钟形对称性 / 物理不对称（跨模型诊断类）

### H-DIURNAL-1 — 峰前(10–12)欠、峰后(13–16)超 → 预测钟形偏对称/偏晚（真实偏早达峰、下午温度降额）
- **机制**：真实光伏功率因下午组件温度升高、效率下降，日内曲线**偏早达峰、下午半边被压低**（不对称、偏向清晨侧）。若模型没建模温度降额、或对日内变化响应滞后，就会画出**偏对称/偏晚**的钟形 → 峰前段低估、峰后段高估。**竞争解释**：预测序列相对真实**整体时移几步**（取点/时区对齐 bug）也会产生同一形态，但那是**数据问题、不是模型性质**（源：光伏温度降额物理 + models.md 各模型温度特征使用情况，待核）。
- **可判别预测**：图#6 分模型 bias 剖面呈 **10–12 点<0、13–16 点>0，穿越零点在太阳正午附近、正午 bias≈0**（说明追峰不是问题、峰高报对了，问题在钟形对称性/相位，不在峰值幅度）。三支判别：
  1. 叠画一天的 pred vs true，若**整条曲线整体右移几步** → 对齐/时区 bug，回 Step 1/2 复核，本条不成立（反驳门#7，须优先排除）。
  2. 排除对齐后若**所有模型同现** → 共因，指向物理温度降额（或共享的气象时刻误差）。
  3. 若**仅未用温度特征（t2m/general_temp）的模型**下午高估更重、用温度的模型较轻 → 温度降额机制证实。反例（可证伪）：下午 bias 不是系统性为正、或穿越点不在正午 → 与本条无关（另查形态 A/B）。
- **验证手段**：图#6（分模型 bias 剖面 + `bias_asymmetry`）+ 叠日 pred/true 对齐自检 + 对照 models.md 各模型温度特征使用 + 图#8（晴天组里这种不对称最清晰，多云天会被云噪声和形态 B 的高估掩盖）。反向索引见 `figure-diagnostics.md` 形态 I。

### H-XSTN-1 — 雅砻江高原季风带未被训练覆盖 → 干季迁移好、雨季 OOD 重

### H-XSTN-3 — 重气象特征的模型比重历史功率惯性的更"站无关"、跨站迁移更优
