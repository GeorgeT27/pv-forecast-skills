## 怎么用这张表

- **列含义**：
  - **ID**：稳定编号，FINDINGS.md 与 ANALYSIS.md 用它交叉引用。
  - **假设（机制）**：源于架构的因果猜测（从 models.md 搬运，非本表新造）。
  - **可判别预测**：如果假设为真，数据上**应当看到什么**、以及**看不到什么**（可证伪才算数）。
  - **验证手段**：用哪张图 / 哪个统计量检验。
  - **状态**：`预注册`（写了预测还没验）/ `证实` / `推翻` / `证据不足`（样本量或信噪比不够下定论）。
  - **证据链接**：证实或推翻时，指向 ANALYSIS.md 小节或图文件 + 日期。
- **状态流转纪律**：
  1. 分析前先读本表，认领相关条目（`预注册` → 本次要验的）。
  2. 看图后按结果改状态；**证实/推翻都要写证据链接**，`证据不足` 要写清是样本量还是信噪比问题。
  3. 结论进 FINDINGS.md 时带上 ID，例如："（H-CHRONOS-1 证实）M1/M3/M4 在 2025-06 同步变差而 M2 稳……"。
  4. 表里没有能对应当前发现的条目 → **先在此新增一条 `预注册`**（写清可判别预测），再去看图验证，不要跳过登记直接下结论。
- 与稳健性门槛、反驳门的关系：本表管"预测是否被数据支持"，稳健性门槛管"差异是否是噪声"，反驳门管"有没有别的解释"。三者都过，结论才升级为 `证实` 进 FINDINGS.md。

## A. 跨模型共享上游（诊断工具类）

### H-CHRONOS-1 — Chronos 单点故障三角
- **机制**：M1/M3/M4 的 observe_power 未来段全部来自 Chronos，M2 完全不用 Chronos（源：models.md M2/M3 分析节、M1 第 34 行）。
- **可判别预测**：若某月 M1/M3/M4 **同步**变差而 M2 相对稳 → 病因在 Chronos 上游；若四者**全部**变差 → 病因转向天气/气象原料/数据，而非 Chronos。反例（能证伪）：只有单个模型变差 → 与本条无关，查该模型自身 tokenizer/损失。
- **验证手段**：图#3（五口径月度对比，分模型看是否同步）+ 图#4（逐样本 RMSE 时间序列，看变差是否同时段）。
- **状态**：预注册
- **证据链接**：—

### H-WXSRC-1 — 气象来源三角
- **机制**：M3 气象 100% 押 solargis（不用九点位 NWP）；M4 solargis 与 NWP 分通道；M1 十路混合；M2 辐照用 SSRD+GHI_solargis、温度只用 solargis（源：models.md M3 分析节、M2 第 70 行、M4 特征节）。
- **可判别预测**：NWP 坏而 solargis 正常 → M3 免疫、M4/M1 受累；solargis **辐照**坏而 NWP 正常 → M3 受累最重、M4 有 NWP 兜底、M1 被十路稀释；solargis **温度**坏 → M2/M3 温度侧全坏，M4 有独立 general_temp（t2m 九点均值）兜底、M1 十路稀释。
- **验证手段**：图#8（分天气型对比）+ 图#10（NWP 误差分离，需前提验证通过）+ 原始列自算 solargis vs SSRD_pos 均值各自对真值的月度误差。
- **状态**：预注册
- **证据链接**：—

## B. 损失函数 → 追峰/压峰排序

### H-LOSS-1 — 损失类型决定午间压峰深浅（M4<M1<M3 追峰强度）
- **机制**：M4 损失等价纯 L1/中位数回归；M1 主损失 Huber（小误差近 MSE）；M3 头级 MSE（追峰最强）。追峰激励 M4 < M1 < M3（源：models.md M4 损失节、M1 第 31 行、M3 第 99 行）。

- **验证手段**：图#6（日内时段 bias/RMSE 剖面，分模型）+ 图#8（分天气型）。
- **状态**：预注册

## C. 输入信息结构 → 时效与天气型特长

### H-M2-1 — M2 无功率惯性 → 时效曲线近平坦、超短期最差
- **机制**：M2 完全不用历史功率序列、无 Chronos，无任何自回归信息（源：models.md M2 分析节第 64 行）。
- **可判别预测**：图#5 时效曲线近乎平坦（只随气象预报质量缓慢变差），而其他模型近时效低、随时效上升；口径上 ultra_short（index 16=4h）M2 相对最差，48hours 差距收窄甚至反超。
- **验证手段**：图#5（分预报时效误差曲线）+ 五口径 Excel 逐口径对比。
- **状态**：预注册
- **证据链接**：—

### H-M2-2 — 九路"先嵌入再求和"保留 NWP 离散度 → 多云/突变天特长
- **机制**：M2 对 SSRD 九路各自嵌入后逐元素求和（DeepSets），非线性下 Σf(xᵢ)≠f(mean)，成员分歧信息部分保留；M4/M1 在输入端算术平均直接丢弃离散度（源：models.md M2 第 69 行、M4 第 132 行）。
- **可判别预测**：成员分歧大的多云/突变天，M2 相对 M4/M1 有独特优势（RMSE 更低或 bias 更小）；晴稳天无此优势。
- **验证手段**：图#8（分天气型对比，重点看多云波动/突变两类）；离散度可从 SSRD_pos_1~9 自算。
- **状态**：预注册
- **证据链接**：—

### H-M4-1 — NWP 离散度被丢弃 → 高离散度月 M4 相对变差

## D. 时间归纳偏置 → ensemble 多样性来源

### H-M1-1 — Fourier 频域偏置 → 晴稳强、多云高频吃亏

## E. 归一化/尺度机制 → 误差形态

### H-M2-3 — 三路等权平均的内生平滑 → 结构性压峰（不套"MSE 追峰"）
- **机制**：M2 损失对每个单气象源头独立算 MSE 求和，从不作用于平均后输出；推理时三路等权平均把辐照头尖峰按 1/3 抹钝，无训练信号纠正（源：models.md M2 损失节 + 第 68 行，机制已由损失代码证实）。
- **可判别预测**：图#1 斜率<1、图#6 正午低估呈 M2 特有结构性形态；净效应方向待图证——不能直接套"M2 头级 MSE→追峰"结论（结构性平均反向抹峰）。反面：单一气象源坏只污染 1/3 输出（稳健性）。
- **验证手段**：图#1（True vs Pred 斜率）+ 图#6（日内 bias 剖面）。
