## 一、分布漂移诊断（训练集 2024 vs 测试集 2025）

训练集不参与指标计算，它的用途是回答第三类“为什么”：**模型是不是遇到了训练时没见过的分布**。
与“NWP 原料变差”（下节）、“模型类内能力退化”（图#8）并列为月度变差的三大候选解释。先重建物理
连续序列再统计（见项目背景的重叠推论）。

三类漂移分开查，结论含义完全不同：

| 漂移类型 | 查什么 | 方法 | 查出来意味着什么 |
|---------|--------|------|----------------|
| 特征漂移 | GHI/SSRD/t2m 及 kt、σΔ 的分布，2025 vs 2024 **同月对比** | 分位数带/小提琴图 + KS 或 PSI | 天气模式偏出训练分布 → 模型在分布外运行，变差是“没见过”而非“学错了” |
| 标签漂移 | 功率分布、日发电量、日峰值 | 同上；重点看台阶式突变 | 台阶 → 扩容/限电/装机变化，查 station.md 与 event-log.md，而不是怪模型 |
| 映射漂移 | 功率-辐照关系 P(power \| GHI) | 两年的功率-GHI 分箱均值曲线叠画 | 曲线整体位移 → 组件衰减、扩容或限电改变了物理映射，所有模型同时受害 |

产出两张图：
- **图#11 同月分布对比图**：关键变量 × 月份网格，2024 vs 2025 分布并排，标注 KS p 值或 PSI；
  stats.json 逐月含 psi/ks_p/中位数/p10/p90。
- **图#12 功率-辐照映射对比图**：两年分箱曲线叠画，差异区间标注。

**标准命令**（代码已固化在 `scripts/run_drift.py`，照下面跑）：

```bash
python <skill>/scripts/run_drift.py --cols "GHI-solargis,observe_power_future"
# --cols 逗号分隔要查的列：气象列=特征漂移、功率标签列=标签漂移；
#        SSRD_pos_* / t2m_pos_* / temp solargis 等按 schema 真实列名补。
```

脚本做三件事：`drift_table`（特征+标签漂移逐变量逐月 PSI/KS 数值表 → `drift_table.csv`）、
`weather_class_drift`（天气型漂移，kt/σΔ 分布 + 五类占比）、fig11/fig12。

- **三类漂移分别对号**：`drift_table` 里气象列 = 特征漂移、功率列 = 标签漂移（看台阶式突变 → 查扩容/
  限电）；`fig12` = 映射漂移（曲线整体位移 → 组件衰减/扩容/限电改物理映射，全模型同害）。
- **共享基准是天气型漂移的命门**：`weather_class_drift` 用 **2024 的包络与 σΔ 阈值**分类 2025，否则
  各年自归一化会把“整体变暗、更多波动天”抹平（`daily_weather_class` 默认 None=自算，只适合单期分析；
  跨年对比必须走 `weather_class_drift`）。
- **结果先落 `drift_table.csv`**，PSI>0.25 的变量-月份才进 fig11 细看；结论进 Playbook A 第 5 步。

结论句式：“2025-06 的 σΔ 分布显著右移（PSI 0.31），多云波动天占比从 2024-06 的 23% 升至 41%——
模型面对的是训练年未充分覆盖的天气模式。”

## 二、NWP 预报误差分离（条件模块——先验证前提再启用）

思路：同一物理时刻会同时出现在早先行的未来 192 段（当时的**预报值**）和更晚行的历史 672 段
（**事后记录值**）里。两者相减即得 GHI/SSRD 的预报误差序列，不需要任何额外数据。由此可把功率预测
误差分解为“气象原料误差”与“模型映射误差”——“6 月掉是因为气象源掉了”从猜测变成可量化证据。

**前提验证（首次拿到数据时执行，通过才能启用本模块）**：

1. 任选若干物理时刻，把它在所有行里的 GHI/SSRD 取值捞出来（不同行 = 不同提前量）。
2. 数值随提前量变化、并在进入历史段后收敛到稳定值 → 历史段是实况回填，**模块可用**。
3. 处处相同 → 历史段只是预报存档，**模块作废**（NWP 质量只能借道晴天功率做代理评估，间接得多）。
4. GHI-solargis 与 SSRD 要**分别验证**：两者来源不同（卫星产品 vs 数值预报），回填策略可能一个可用
   一个不可用。

验证通过后产出**图#10**：NWP 预报误差月度曲线（按月/按提前量聚合），与功率 RMSE 月度曲线叠画——
两线同步上升即“原料”问题的直接证据。验证结果（可用/作废）记入 FINDINGS.md，避免每次重验。
