# 链路图：Rollout 与反传（2026-09-01）

## 图 1：Rollout 链路（做题 → 收卷 → 拼图 → 打分）

```mermaid
flowchart TD
    subgraph PREP["考场准备"]
        SKILL["当前版本技能<br/>ts-diagnose playbooks"]
        CASE["冻结考题<br/>C1/C2/C3 + gold 标准答案<br/>agent 不可见"]
    end

    subgraph RUN["agent 盲跑做题"]
        ORIENT["看数据 / 选 playbook<br/>(intake + data-setup)"]
        HYP["提假设 H1..H4<br/>写入假设账本"]
        INTV["干预实验<br/>子代理并发执行<br/>每个假设 3 种子训练"]
        RCPT["开小票 receipt<br/>改了什么开关 / delta / 口径<br/>+ 溯源四件套 produced_by"]
        VERD["判决 supports/refuted/undecided"]
        CONC["写结论 CONCLUSION.md<br/>须过 conclusion_gate 硬闸"]
        ORIENT --> HYP --> INTV --> RCPT --> VERD --> CONC
    end

    SKILL --> RUN
    CASE --> RUN

    subgraph TRACE["做题留下的三样东西"]
        ART["答题卡：产物文件 ~45 个<br/>账本/计划/小票/判决/结论/闸报告"]
        TS["监控录像：转录<br/>每句话每个工具调用"]
        PROBE["埋点：stage_probe 时间戳"]
    end

    RUN --> ART
    RUN --> TS
    RUN --> PROBE

    subgraph HARVEST["收卷（全自动脚本）"]
        FREEZE["冻结全部产物"]
        SEG["segments.py 从录像抽段<br/>~9 段，边界=时间戳"]
        BUILD["graph/build.py 拼图<br/>硬证据连边：H 号逐字对上 /<br/>数字位级相等 / sha 指纹一致<br/>拼不上显式记 gap"]
        GRAPH["graph.json<br/>~91 节点 / 128 边 / 21 gap<br/>谁生成谁·谁引用谁·谁支持谁"]
        FREEZE --> BUILD
        SEG --> BUILD
        BUILD --> GRAPH
    end

    ART --> FREEZE
    TS --> SEG
    PROBE --> SEG

    JUDGE["judge 对照 gold 打分<br/>输出哪条结论错 + refs 指认 H 线"]
    GRAPH --> JUDGE
    CASE -. gold .-> JUDGE
    JUDGE --> OUT["分数 + 错误信号<br/>↓ 进入反传（图 2）"]

    style GRAPH fill:#2b6cb0,color:#fff
    style JUDGE fill:#805ad5,color:#fff
    style OUT fill:#c53030,color:#fff
```

## 图 2：反传链路（锚定 → 第一层机械验证 → 第二层决策审查 → 改说明书）

```mermaid
flowchart TD
    FAIL["错误信号：结论错了"]

    subgraph ANCHOR["入口：锚定级联（能锚多低锚多低）"]
        A1{"gate 报告<br/>点名了吗？"}
        A2{"图警报灯扫描：<br/>gap / delta 矛盾 /<br/>种子不够 / 文件不存在？"}
        A3{"judge refs<br/>指认了 H 线？"}
        A4["微型锚定调用：LLM 看<br/>全图鸟瞰卡片挑一条线"]
        A1 -- 没有 --> A2 -- 没有 --> A3 -- 没有 --> A4
    end

    FAIL --> A1
    A1 -- 有 --> START
    A2 -- 有 --> START
    A3 -- "有→只拉该 H 线十来个节点" --> START
    A4 --> START

    START["锚点 = 反传起点"]

    subgraph L1["第一层：机械验证反传（脚本，不用 agent）"]
        WALK["逆拓扑走到下一个节点"]
        HASV{"这类节点<br/>有验证器吗？"}
        OP["三档算子按成本试：<br/>① 确定性重算（毫秒，开父节点原料按声明口径算）<br/>② 补 seed 重放（用考场标准评测器，不用 run 自己的脚本）"]
        CLEAN{"声明 vs 重算<br/>对得上？"}
        UNV["标 UNVERIFIABLE 攒批<br/>（语义声明等无契约节点）"]
        UP{"父辈全部<br/>验证干净？"}
        INTRO["停：此节点 = 错误引入点<br/>produced_by = 元凶脚本<br/>descendants 一跳 = 作废清单"]

        WALK --> HASV
        HASV -- 有 --> OP --> CLEAN
        HASV -- 无 --> UNV --> WALK
        CLEAN -- "干净 → 继续往上" --> WALK
        CLEAN -- 脏 --> UP
        UP -- "否 → 错更早，继续上" --> WALK
        UP -- "是（自己脏父辈净）" --> INTRO
    end

    START --> WALK

    SEMREV["agent 语义审查 UNVERIFIABLE 批<br/>带上下文：其余节点已全净，只看这几条<br/>输出=嫌疑标注（非定罪）"]
    UNV -.批量攒完.-> SEMREV
    SEMREV --> REPLAY1["重放定罪 / 降级待验证"]

    ALLCLEAN{"全部节点验证干净<br/>但结论仍错？"}
    WALK -. 走完全线无发现 .-> ALLCLEAN

    subgraph L2["第二层：决策审查（图当调度台，agent 读录像）"]
        LOC["图定位：可疑产物属哪段、<br/>谁写的（主 agent / 哪个子代理，<br/>executes 边——并发线必须切对人）"]
        WIN["掐时间窗：<br/>前一事件结束 → 产物落盘<br/>（段 t_enter/t_exit + 小票 t_start/t_end）"]
        SLICE["切该执行者的转录切片<br/>= 思考现场"]
        READ["agent 读现场找拐错弯处<br/>+ consumes 边给它当时手里的材料<br/>输出=线索（低信任，非证据）"]
        REPLAY2["重放定罪"]
        PROD["同类决策错第 2 次 →<br/>产物化：强制结构化文件+闸门<br/>新契约+新验证器 → 划归第一层"]
        LOC --> WIN --> SLICE --> READ --> REPLAY2
        REPLAY2 --> PROD
    end

    ALLCLEAN -- 是 --> LOC

    subgraph EXIT["出口：改说明书（LLM 提案，机器验收）"]
        BLAME["定罪报告 JSON：引入点/错误类型/<br/>声明值 vs 重算值/作废清单/governed_by 条款"]
        DRAFT["agent 读定罪报告+两端原文+条款原文<br/>起草一个最小编辑<br/>（倾向机械化：手抄改脚本注入）"]
        ACCEPT{"串行验收：一轮只改这一处<br/>冻结题库重跑 + holdout 回归"}
        MERGE["接受，进下一轮"]
        ROLLBACK["回滚 + 记反对票"]
        BLAME --> DRAFT --> ACCEPT
        ACCEPT -- 分数升 --> MERGE
        ACCEPT -- 不升 --> ROLLBACK
    end

    INTRO --> BLAME
    REPLAY1 --> BLAME
    REPLAY2 --> BLAME
    PROD -.验证器清单增长.-> HASV

    style FAIL fill:#c53030,color:#fff
    style INTRO fill:#c53030,color:#fff
    style L1 fill:#f0fff4
    style L2 fill:#fffaf0
    style BLAME fill:#2b6cb0,color:#fff
    style MERGE fill:#276749,color:#fff
    style ROLLBACK fill:#975a16,color:#fff
```

## 两张图的接缝

- 图 1 的输出（graph.json + judge 错误信号）= 图 2 的输入；
- 图 2 出口"接受"后产生新版说明书 → 回到图 1 开始下一轮 rollout——这就是完整的进化循环；
- 图 2 里的虚线"验证器清单增长"是领土转移机制：决策产物化让脚本的地盘随轮次扩张，agent 的判断力收缩到真正开放性的残余上。
