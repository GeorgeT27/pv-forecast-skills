## A/B 设计

- **控制变量**：同一 rep（含注入靶 A 的副本），只换反思管线。不重跑 rollout。
- **V0 管线**：build_reflection_input 按段全量 bundle → 单次 LLM 反思（"哪错了、改什么"）。
- **V_new 管线**：锚定级联 → verify.py 反传（机械算子①②）→ agent 逐节点判读（③，嫌疑级）
  → 重放队列（模板内脚本构造/模板外 agent 设计，执行全脚本）→ 两栏定罪报告 → 编辑草案。
- **测量**：①定位精度（对照四靶已知答案：引入点/嫌疑/段+执行者 是否命中）②证据可查性
  （每条结论可否点开到原始文件+数值）③token/LLM 调用数 ④重放触发次数与判定。
- **诚实边界**：n=1 演示不是统计结论；注入靶好找于自然靶（Who&When Pro 警戒）在 demo 里写明。

## 实验结果（2026-09-01 完成，全部落盘）

**验收四靶全中（正控）+ 原始 rep 41 节点全洗清零误伤（负控）+ 108 测试绿。**

- 靶A：反传唯一引入点=H3 回执（声明 −0.0117 vs 独立重算 +0.00087，差 0.0126；干净回执残差 1e-8——七个数量级间隔）；元凶=eval_H3.py（孤儿回执如实标注命名候选）；作废清单=账本/判决/结论。
- 靶B：警报灯扫出 21 gap + H2 顶层 schema 薄；验证器下钻嵌套洗清误报。
- 靶C：agent 判读嫌疑→seed=2027 真训练 2 次→4 种子 delta 收敛 −0.0003 仍 undecided→**洗清**，残差升规则层（与 judge 反馈独立吻合）。
- 靶D：产物全净→第二层图定位 seg:04（44 秒窗）→切转录→线索"模板默认值静默继承"→1h 重算坐实：h12 z=−4.2 与 h13/14/15 z=+5.4/+7.1/+8.3 在 4h 桶内反向对消成 z=0.35（与 gold z≈5-11 吻合，掩盖机制曝光）。

**A/B 判分**（详见 demo/comparison.json）：四靶 V_new 4/4 完整命中；V0（无工具摊开、输入含 judge 反馈）0 完整 + 3 半命中（H3 只抓到保守规则违反、把假数当真；C/D 方向对但无实验证据）+ 1 独立优势（"5 vs 6"手数错，V_new 无此契约未抓——候选新验证器）。token：V_new 3 次调用（输出 ~3.3 万）+ 2 次真训练；V0 单次 ~22 万入/2.9 万出。**V0 三轮输出漂移（首位错误各不同），V_new 机械层逐轮逐字节相同。**

**过程中的方法论收获（与结论同等重要）**：
1. 注入工艺四轮迭代——前三版留内部矛盾破绽全被 V0 一致性细读抓住（口径改写需同步 15+ 处：回执主体/保守复核/守卫记录/脚本代码/账本/汇总/FINDINGS/PROGRESS/结论双行）→ 实证"注入错误偏容易"的文献警戒，也实证 V0 强于一致性阅读、无工具时识不破需要独立重算的口径本质。
2. claude -p 默认带工具：V0 首轮翻盘上原版对答案（cache_read 340 万暴露多轮循环）→ 反思调用必须 --allowedTools 禁令，已固化进 reflect/llm.py。
3. 反传验证器在实验中被打出一个真 bug 并修复：结论的保守复核行须按行内 noise_floor 对账 conservative_recheck 而非主判决（schema 感知）。
