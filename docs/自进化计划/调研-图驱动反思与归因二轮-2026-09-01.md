# 调研（二轮）：图驱动的反思与错误归因（2026-09-01）

> 五个并行检索视角（图记忆主流线 / 重放因果线 / 归因基准线 / 自进化编辑线 / 批评方法学线），
> 合计约 60 轮检索、约 100 篇逐篇打开 arXiv abstract 页核实；UNVERIFIED 条目不承重。
> 对照对象：graph-v1 已落地（91 节点/128 边/21 gap），第 2 步计划 = 三层反思装载
> （图信号清单 → ancestors 闭包候选段全量 → 其余段一行卡片）+ 补 seed 重放 + 串行接受协议。
> 上一轮调研见 调研-轨迹归因与梯度式编辑-2026-08-31.md；本文只报增量与对照判定。

---

## 总判定

1. **图底座的投资被新文献强验证**：完整可查轨迹使归因准确率最高 +76%（TraceElephant）；
   依赖图输入稳定带来 +10~17pp（CHIEF/FALAT/CockpitHAT 一线）；EviGraph 的设计与我们
   几乎一一对应（typed 假设/实验/发现节点、图即操作状态、反思=定位最早弱节点再生下游子图）。
2. **三层装载方向正确，但呈现方式要改**：图用于**机器侧选择**（选段、选文件、排序）证据充分
   （Engram：图切片 83.6% vs 全历史 73.2%，1/8 token）；但把图结构**序列化进 prompt** 增益
   边际甚至为负（2511.16767），RoPE 会系统性压制序列化后相距远的依赖对（2606.15633）。
   结论：图归机器查，反思器收到的是**扁平文本+相关内容物理相邻**，不是画出来的图。
3. **补 seed 重放的地位不降反升**：图引导归因的旗舰之一 GraphTracer 因方法学错误撤稿；
   步级定位在自然失败设定下两年仍未过 40%（29.1~37.8%）；重放翻转仍是唯一因果判据。
   且"图查询→最小重放集合"的形式化在文献里仍是空白——我们的 consumes 闭包方案没有被抢跑。
4. **新增三个必须吸收的警戒**：反复固化改写的文本记忆会崩（保留原始轨迹准确率翻倍）；
   结构化反思问题清单被消融判零增益（有效成分只有 typed action routing）；
   自进化循环有 rise-then-collapse 风险且无人对 playbook 文本通道验证过。

## 研究问题

- RQ1：有了机器可查的溯源 DAG，反思的上下文装载有什么比"两段式窗口"更新的做法？
- RQ2：溯源图查询 × 反事实补丁重放的结合有什么新工作？
- RQ3：新文献里哪些支持、哪些反驳、哪些能改进现有计划？

## 方法

五个对抗性视角并行独立检索（主流/重放/基准/进化/批评），每视角 15~25 轮、先宽后窄；
全部候选逐篇 WebFetch 打开 arXiv abstract 页核实存在性与题摘相符，打不开标 UNVERIFIED 不入正文。
交叉验证：8 篇被 ≥2 个视角独立发现（CHIEF、TraceElephant、Who&When Pro、GraphGPO、
Deterministic Graphs 2605.06365、GraphTracer 撤稿事实、When CL Moves to Memory、TELBench），
视角间空白判断互相印证无矛盾。已知盲区：一篇被引的 "trajectory graph copilot" 两轮定向检索未找到原文。

## 分支一：图作为反思的操作状态（RQ1 主脊）

2026 年出现了一小批"图不是事后记录、是运行时操作状态"的工作，与我们的 graph-v1 同构度极高：

- **EviGraph**（2608.04738）：研究过程 = Problem/Gap/Hypothesis/Experiment/Finding/Claim
  六类 typed 节点的 evidence graph；反思 = 检查证据链的缺失依赖/语义错位/结果-断言不一致
  → 定位**最早弱节点** → 只再生受影响的下游子图，配图 checkpoint 防修复污染。
  这与我们"gap 清单 + delta_consistent 矛盾边 + descendants 作废清单"是同一件事的两种写法；
  它的增量是"修复后只再生下游子图"——对应我们第 2 步重放后的**选择性重算**，可直接借鉴。
- **LEDGER**（2608.18398）：claim→evidence 分层 trace graph 供审计——即我们规则 6 证据清单
  + evidence_ref 边的独立发明，佐证该机制的方向正确。
- **MAP-Graph**（2608.10509）：把 provenance 从事后审计升级为**运行时控制信号**（准入过滤/
  信任评估/风险门控）。对应我们推迟的"阶段闸时刻拼部分图"候选想法——文献已有人走通。
- **Praxist**（2608.25955）：把产物+评测结果转成 evidence graph，后续尝试继承已验证机制/
  未决断言，成本降到 1/12——跨 rollout 的图化经验继承，对应我们推后的跨版本总图，可作参照。
- **DoCtOR**（2608.28264）：先归因出决定性错步，**只让肇事 agent 定向反思**，明确论证
  全员反思会污染无辜 agent 的记忆——"候选段全量、其余段卡片"的选择性装载多了一条独立论据。

五视角空白判断的交集（真空白，非检索盲区）：**"receipt/回执作为图节点类型"、"干预及其结果
持久化入图供后续查询"、"溯源子图作为反思 prompt 的组装材料"三者均无直接文献**；
"provenance graph + reflection" 组合检索几乎零命中。我们的假设-干预-回执-判决四类节点
设计占住的是一个真实空档。

## 分支二：图驱动的上下文装载（RQ1 装载侧）

图记忆谱系（AriGraph/Zep/A-Mem 后续）2026 年的共同转向是"图=索引而非库"（LiCoMemory
2511.01448 的表述），检索从静态相似度变成图上主动遍历：

- **Engram**（2606.09900）给出关键定量：bi-temporal 图上取 ~9.6k token 检索切片，
  83.6% 击败全历史装载的 73.2%，token 只用 1/8——选择性装载既省又准。
- **2605.08217** 恰好在**时序预测域**（我们的域）实证反向 scaling：上下文变长误差上升
  （3000 步窗口性能降 >68%），选择性检索胜长上下文——"长上下文让选择性装载过时"的担忧可以放下。
- **ContextWeaver**（2604.23069）：推理步依赖 DAG 按依赖遍历选上下文，取代滑窗——
  即 ancestors 闭包装载的独立发明。
- **CICL**（2606.08151）更进一步：按"对下游动作的**反事实决策效用**"而非语义相似度/
  图可达性排序候选证据——闭包内文件太多时的**第二级排序准则**，比"闭包内全装"更精。
- **MAGMA**（2601.03236）：同一记忆挂语义/时间/因果/实体四张正交图，检索=跨图遍历——
  与我们"时间靠段、归属靠 ID、核实靠 sha"三轴同构的多轴设计。

**反面**（批评线，必须吸收）：2511.16767 系统消融发现 LLM 读 text-attributed graph 时
"仅节点文本已达强性能，多数结构编码增益边际甚至为负"；2606.15633 给出机制——RoPE 使
序列化后相距远的相邻节点注意力被压制。两篇的场景是图分类任务而非 agent 诊断上下文
（直接迁移有折扣），但方向明确：**图的价值在机器侧查询与选择，不在把邻接结构画给模型看**。
装载产物应是"按依赖顺序排列、相关条目物理相邻的扁平文本"。

## 分支三：失败归因的新格局（RQ2/RQ3 证据基线）

**基准侧**：Who&When Pro（2607.09996，12,326 条轨迹×26 benchmark）显示受控注入设定下
文本步级最好 ~73.9%，但 error-mode macro-F1 仅 22.2%，轨迹 >12K token 时步级 94%→50%，
模型按表面相似归类而非追根因。TraceElephant（2604.22708）：完整 trace 相对只看输出
归因准确率最高 +76%。AgentRx（2602.02475，微软）步级比 prior work +75%。
2605.14865 的关键发现：同一前沿模型在结构化评估框架内定位准确率比当整体 judge 高数倍——
**此前的 12~34% 低分很大程度是评估协议的产物，瓶颈在方法学而非模型能力**。

**方法侧三条路线**：(a) 结构化输入（CHIEF 层级因果图、FALAT 依赖引导搜索、CockpitHAT
依赖距离阈值，自然失败设定下步级 29.1~37.8%，较基线稳定 +10~17pp）；(b) 干预/重放式
（REFLECT、CAR、VerifyMAS——后者"先构造失败假设再对全轨迹验证"与我们假设账本→验证主脊
同构）；(c) 专训小模型（AgenTracer/Aegis/AFANet）——但该路线旗舰之一 **GraphTracer
（2510.10581）已于 2025-12 因"方法学根本错误"撤稿**，专训归因器的数字需打折。
三路线从未同基准三方对比。FALAT 有一个可直接搬的概念：区分**引错步**与**传播步**
（error-introducing vs error-propagating）——我们的污点传播目前不分这两者。

**对我们评测集的直接警告**：注入错误比自然错误好找是公认偏差（Who&When Pro），而我们
Tier2 C1-C3 正是注入式；另有 benchmark 审计线（2607.22368：15 个 benchmark 中 67% 轨迹
存在答案暴露/reward hacking；BenchJack 2605.12673：不解任务即拿近满分）——
盲推评测若上马，需先做题目级审计 + "不做分析直接产 receipt 能否骗过闸门"的红队测试
（规则 5 的 sha+schema 机检已挡住最粗的一档，但未测过对抗式）。

**静默失败监控**：2606.09863 强证据——LLM judge 当监控器不可靠（AUROC≤0.65），
轻量 TF-IDF 检测器反而 0.83/0.95 且延迟低 3300 倍。支持我们"确定性闸门第一道、
LLM 永不当第一道 checker"的既有铁律，并提示监控器可以便宜到荒谬。

## 分支四：图 × 重放的桥（RQ2 主脊）

真正把"图定候选"与"重放判定"接起来的只有四篇：**CHIEF**（图剪枝候选→渐进反事实筛选）、
**Shepherd**（2605.10913，Git 式可逆 trace，从首次分歧点分叉重放）、**DoVer**（2512.06749，
checkpoint+定向干预，恢复 18~28% 失败任务）、**Zero-Replay**（2606.14805，知识图谱
**预测**重放结果、省真重放）。基础设施侧：agrepl（2607.16200，传输层截获重放，250 实例
完美保真）、ActiveGraph（2605.21997，append-only 事件日志任意点廉价分叉）。

理论最干净的是 **C3**（2603.06859）：利用"交互历史是可观测文本的确定函数、无隐状态"
这一性质做精确上下文恢复 + leave-one-out 无偏归因。**我们的收卷产物恰好满足这个前提**
（收卷全集+sha+确定性拼图），即我们的重放在理论上可以做到 C3 级的干净。

**空白 = 我们的机会**（重放线视角的判断，原文照录要点）：没有工作把溯源图查询形式化为
**最小重放集合的选择器**并给出候选数/重放预算的理论界；"图确定最小状态"与"重放翻转判定"
之间缺正确性衔接（ActiveGraph 能任意分叉但不答在哪分叉，FALAT 能出候选但不做翻转）；
评测端没有"最小重放集合选得对不对"的评测轴。我们"consumes 闭包 = 重放最小状态"的方案
写出来就是这个空白的第一个系统实现。

## 分支五：自进化编辑与 skill 生命周期（RQ3 循环层）

2026 年 3~7 月 skill library 方向密集爆发（Skill* 一族 ≥12 篇 + 124 文综述
Dynamic Agent Skills 2607.10113），从空白变红海。对我们最有用的三篇：

- **SkillAudit**（2606.14239）：同一任务**带/不带候选 skill 各跑一次做配对审计**，
  行为差异映射回 skill 文档的具体段落，Refine（删坏指导）或 Repair（换冲突段落）。
  这是"blame 落到 playbook 条款"的一条比 aPSF 更便宜的实现路径——aPSF 要因子化全文，
  SkillAudit 只需配对 run。
- **SEPO**（2608.28067）：prompt 切成类型化单元做局部编辑，并维护 **edit-effect lineage**
  （每个编辑新修好/新弄坏哪些样例，作为后续编辑的可审计因果反馈）——串行接受协议的
  CE 账本应加这个字段：每条被接受的编辑记录其冻结集上的逐案例翻转清单。
- **SEAGym**（2606.17546）：对 harness 更新做 train/val/test/replay/成本五维评估，
  专门区分"可复用改进 vs 过拟合/退化"——我们冻结集验证协议的对表对象。

**退化警戒**（批评线）：2605.09315 实证自进化非单调（web 推理三轮 23.2%→8.5%），
capability-preservation 约束可救（41.8%→52.8%）；2606.21090 自训练 rise-then-collapse
（数十步内峰值后崩，抗常规缓解）。两篇都不在 playbook 文本通道——"GEPA 式 playbook 进化
会不会同样崩"无人验证，既是我们的风险也是发表空白。工程含义：串行接受协议必须配
**能力保留 holdout（老案例回归项）+ 峰值检测/回滚**，我们的"不升即回滚+DOWNVOTE"已有
回滚，缺的是跨轮次的峰值追踪。

**记忆固化警戒**：2605.12978——LLM 持续固化（consolidation）的文本记忆先升后降至
低于无记忆基线（GPT-5.4 带记忆在曾解出的题上反而失败 54%）；保留原始 episodic 轨迹
比持续改写摘要准确率翻倍。直接支持我们"图当索引+按需下钻原文件、原始产物永不改写"；
直接警告 crystallize 固化代理与 MEMORY.md 式反复重写——固化产物应 append 版本化，
且反思输入永远能回到原始轨迹。

**反思结构警戒**：2608.12322 受控消融——结构化诊断问题清单相对自由反思**零增益**
（F1 0.296 vs 0.297），唯一有效成分是 **typed action routing**（按发现类型路由到
不同动作，ΔF1=+0.101 跨模型复现）。含义：反思 playbook 不要堆问题清单，要把
"图信号类型 → 动作"的路由表写死（gap→补字段、delta 矛盾→重放、单 seed→补 seed）。
2604.22273 补充停机判据：Error Introduction Rate <0.5% 是自纠错获益/受害的锐利边界，
verify-first 提示可把 EIR 2%→0%——反思迭代轮数应设上限并配 verify-first。

**其余空白维持原判**：文本域 trust region 无人形式化（POaaS drift cap 仍是最近替身）；
批量编辑冲突检测仍无系统方法（SkillAudit 的 Repair 沾边）——串行接受绕开的决定继续有效。

## 交叉综合：三条张力线

1. **"结构有用"与"结构没用"不矛盾，分界在谁消费**。归因/选择侧（机器查图）+10~17pp
   与 +76% 可观测性红利；阅读侧（LLM 读序列化图）零增益甚至为负。同一张图，
   机器查询是资产，画进 prompt 是负债。
2. **注入与自然的鸿沟无人量化**。受控注入 73.9% vs 自然失败 <40%，两年无论文正面量化
   这条鸿沟——我们的评测集横跨两侧（注入式 Tier2 + 自然 Tier1），有第一手数据可说话。
3. **归因方法的自验证缺失**。GraphTracer 撤稿、Credit Without Ground Truth 的 shuffle
   警告、LLM-judge 信度≠效度（2606.19544）——归因结论必须过重放翻转或等价硬判据，
   这条上一轮的修正二被本轮证据进一步加固。

## 开放问题（合并五视角）

1. 溯源图查询 → 最小重放集合的形式化选择器（候选数/预算界）——空白，我们在做的就是它。
2. receipt/干预作为持久化图节点——空白，graph-v1 已实现，值得写出来。
3. playbook 文本通道的自进化退化——无人验证，风险与发表机会并存。
4. 注入 vs 自然失败的归因难度鸿沟量化——空白。
5. 文本域 trust region、批量编辑冲突检测——维持空白原判。
6. "INDEX/图结构上下文对 agent 的增益"消融——2511.16767 只覆盖图分类任务，
   agent 诊断场景的有/无对照是可发表的第一手实验。

## 结论：逐 RQ 回答 + 计划对照

**RQ1（图驱动装载的新做法）**：有三个可吸收升级——(a) 装载产物形态：图归机器查询，
反思器收扁平文本、相关条目物理相邻（2511.16767/2606.15633）；(b) 闭包内二级排序：
按反事实决策效用而非仅可达性（CICL）；(c) 反思动作化：问题清单换成 typed routing 表
（2608.12322），配 EIR 停机判据（2604.22273）。三层装载骨架本身被 Engram/DoCtOR/
TraceElephant/2605.08217 四路独立支持，不动。

**RQ2（图×重放）**：四篇桥类工作（CHIEF/Shepherd/DoVer/Zero-Replay）确认方向，
C3 确认我们满足精确重放的理论前提；"图查询→最小重放集"的形式化仍是空白。
补 seed 重放照原计划做，可加一个便宜前置：Zero-Replay 式"图上预测翻转概率"
给重放排预算优先级（启发式即可，判定仍以真重放为准）。

**RQ3（对现有计划的逐环节判定）**：

| 计划环节 | 判定 | 依据 | 动作 |
|---|---|---|---|
| 图底座 + gap 纪律 | ✅ 强支持 | TraceElephant +76%；EviGraph/LEDGER 同构；receipt 节点空白 | 不动；值得对外写 |
