# 阶段 1：architecture-attribution playbook 构建

三阶段总览：**阶段 1（本报告）= 造能力**，阶段 2 = 造裁判（评测集），阶段 3 = 造优化器（进化循环）。依赖关系：阶段 1 与阶段 2 互相咬合（案例构造过程即 playbook 流程的人肉原型，C1 已验证），阶段 3 依赖前两者完成。

## 1. 目标与定位

ts-diagnose 的第 12 个 playbook。解决的问题：现有分析只读指标（"RMSE 下降了"），无法归因到模型结构（"attention 容量不足导致 peak 削平"）。根因不是措辞，是证据天花板——无干预手段就无因果结论。本 playbook 把干预能力接进分析流程。

产出物：三条腿结论。
1. **切片测量**：差异在哪些 lead time / 时段 / 变量 / 分组上真实存在（超噪声底，z>3）；
2. **机理假设**：指向模型代码中具体组件的可否证假设（来自 model-audit），干预前预登记；
3. **干预验证**：单变量消融的实测 delta，判定为确认 / 否证 / 未决。

三条腿不齐的因果表述一律不得进入结论。

## 2. 上游依赖（沿用现有 upstream 声明机制）

| 上游 | 提供 |
|---|---|
| data-setup | 预测/真值对齐长表 + 时间索引（切片分析的前提） |
| fact-scan / result-eval | 误差签名产物（分 lead/时段/变量的误差分布图表） |
| model-audit | 模型档案：组件清单、每个组件的可干预开关（配置项/代码位置）、归一化与嵌入方式 |
| （新增前置）噪声底测定 | 同配置 ≥3 种子的指标方差；无噪声底则本 playbook 拒绝启动 |

## 3. 流程五阶段

### 3.1 现象定位
- 先看池化指标差异是否超噪声底。**超不过也不终止**——C1 实证：池化差距 0.0073 < 噪声底 0.0102，但切片层 z 高达 10。
- 标准切片维度：lead time 分桶、预测时刻（hour-of-day）、变量/通道、目标窗口波动性分位。领域可扩展（光伏：辐照度分档、晴雨天）。
- 每个切片跨种子做配对差值 z 检验，z>3 记为真实差异，z≤3 记 `~noise`。

### 3.2 机理假设生成
- 输入：切片版图 + model-audit 模型档案。
- 指纹库（误差签名→候选组件映射）**只是假设生成器，不是结论器**。每条假设必须：(a) 指向代码中具体组件；(b) 给出可否证预测（"若杀死组件 X，优势应在切片 S 上消失"）；(c) **干预前预登记，事后不得改**。
- 每轮 2–3 条假设，按判别力排序（一次干预能区分最多假设的优先）。

### 3.3 判别性干预设计
- 单变量纪律：一次只动一个组件，种子/数据/训练步数/其余超参全部固定。
- 每个干预 ≥3 种子（与噪声底同种子集）。
- 干预必须**双向可判**：设计时写明"什么结果算确认、什么结果算否证"。只能确认不能否证的干预不合格。
- 预算阶梯（借 feature-blame v3）：先跑判别力最高的一个干预，按结果决定是否追加，单轮上限约 10 次训练。

### 3.4 执行与判定
- delta 与噪声底比较，三种判定：**确认**（预测方向成立且超噪声底）/ **否证**（预测方向不成立）/ **未决**（delta 落噪声底内或种子间不稳定）。
- 否证后允许提出新假设，但必须标注"事后假设（post-hoc）"，且需要新的干预才能升级为确认——不许用同一批数据既生成又确认假设。

### 3.5 结论落笔与结论闸对接
- **结论闸新硬规则**：任何架构层因果表述必须附消融 receipt（配置 diff + 实测 delta + 噪声底对照 + 种子数），附不出的自动降级为"未验证假设"并显式标注。
- 否证和未决是合法且必须报告的产出。禁止在否证后当轮补一个未经干预的替代故事作结论。
- receipt 进入 conclusion_gate 现有格式，新增 `ablation_receipts` 字段。

## 4. 从 C1 固化进 playbook 的三条教训

1. **预登记纪律**："patch 保留时间局部性"假设流利专业，30 分钟内被干预否证——机理叙事在测量前一文不值，playbook 中假设登记与干预执行必须分步、有存档。
2. **家族叙事的死法**：单一反例不足以确认家族级解释（"通道独立模型都更好"被 DLinear/NLinear 不复现版图否证）。家族级假设需要家族内 ≥2 个成员的证据。
3. **池化平局 ≠ 无差异**：切片测量是发现真实版图的必经步骤，playbook 不允许在池化层面下"无差异"结论。

## 6. 验收标准

1. 对 C1 的冻结产物盲跑（不给 gold），能复现三条腿：找到切片版图、生成含局部性假设在内的候选、设计出 I1/I2 同类干预、正确报告否证；
2. 结论闸能实际拦截一条无 receipt 的架构因果结论（构造反例测试）;
3. 在一个 N 类（不显著）案例上敢下"未决/不显著"判定。

## 7. 工作量估计

playbook 正文 + 两个脚本泛化 + 结论闸改造 + v2 卡片：1–2 个工作日；验收测试依赖阶段 2 的 C1 定稿。
