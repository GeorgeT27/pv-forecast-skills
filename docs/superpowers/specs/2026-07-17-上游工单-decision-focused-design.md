# 上游气象模型的 DFL 归因-重训方案（决策导向 + Agent 编排）

> 状态：设计稿 v2（DFL 主线）｜日期：2026-07-17｜关联技能：`pv-feature-blame`
> 一句话：拟合一个可微功率代理，把"功率损失"经它反传进气象模型微调（decision-focused），
> 让气象模型**在功率真正在乎的地方加精度、在无关处放水**；反事实降级为代理梯度的抽检；
> Agent 负责编排闭环、把误差图归因成物理假设、搜索配置、对抗式抽检——不碰数值核。

---

## 0. 目标与范式

**目标**：不发"预测准"的废话，而是产出一个**帮助上游气象模型重训的、有舍有得的训练信号/函数**——
定位"哪个特征、什么处境"的误差真正拖坏功率，让上游把有限精度花对地方。

**范式：Decision-Focused Learning（DFL）**——上游预测按**下游任务损失**训，而非按预测精度训。
选型结论（已与用户确认）：**走 DFL（代理反传全梯度）**，理由——信号最丰富（逐点逐特征连续，
而非分箱粗权重）、基本免疫 Byrd-Lipton（真附加损失项而非乘性重加权）、单层无双层不稳定。
元学习权重表仅作"上游锁死、只收标量权重"时的**兜底**（§5）。

---

## 1. 三组必须先分清的量（地基）

1. **A 当前模型敏感度 vs B 重训管道增益**：反事实只给 A（模型固定）；我们要 B。
  **B 的唯一真检验 = 上游按新损失重训后、独立留出集上功率误差降没降**（§8）。DFL 直接优化 B 的代理。
2. **ε_sys 系统偏差 vs ε_res 波动残差**：`ε=X_pred−X_true`，`ε_sys=E[ε|模型可见且稳定的条件]`（模型
  能补偿、可能已被吃掉），`ε_res=ε−ε_sys`（补偿不了）。**只在 ε_res 方向可信**（§4 守卫），
   ε_sys 方向是代理 OOD 区。
3. **R 可回收总量 vs s 单位斜率**：DFL 用**梯度**（≈s，逐点连续）当训练信号；R 只在"给人看的
  工单/热力图"里出现。**不再手算** `w=value×s²×reducibility`——三因子被"功率损失+留出验证+
   代理梯度"自动吸收（见 §2.4）。

## 2. 核心：DFL 主线



### 2.1 三个部件（默认走校正网）

- **可微功率代理** `ĝ`：拟合黑箱功率 API 的 **seq2seq**（TCN/因果卷积起步）。**linchpin**——让功率
模型偏好可微，梯度才能流进上游。**保真度闸**：留出序列级 R² vs API 达标 + Jacobian 抽检才往下走。
- **可微时序校正网** `C_ψ`**（默认微调对象）**：把预报特征序列 → 校正后特征序列（各 192 点）。时序架构
才能修相位/时机误差（云晚到 30 分钟这类 `ε_res` 是相位误差，逐点缩放救不了）。**若能拿到气象
模型** `Φ` **的权重+输入**，可升级为直接微调 `Φ`；否则校正网是可落地、always-available 的形态，
且本身就是"可交给上游的可训练函数"。
- **决策导向损失**：见 §2.5（`L_power + L_anchor + L_sys-penalty`）。

**DFL 输入（喂给** `C_ψ`**）**：只用**预报时刻拿得到的量**——`X^pred`（待校正的预报序列）+ 上下文
（历史 672 观测、时刻/季节/太阳几何、提前期、天气型、其它预报特征）。`X^true` **绝不作为网络输入**
（部署时上游没真值），它只在训练里当 `L_sys-penalty` 方向 / reducibility 诊断的信号。输出 = 校正后
192 点特征序列 → 喂冻结 `ĝ` → 得功率 → 算损失。

### 2.2 流程

```
① 拟合可微代理 ĝ ≈ 功率API（一次性）+ 保真度闸
② 组 L_down（经 ĝ）；混合 α·L_weather 防遗忘
③ 微调副本 Φ_ψ 降 L（梯度 L_down→ĝ→Φ_ψ 自动告诉气象模型"这里调能动功率"）
④ 蒸馏成可解释产物：对比「微调后 vs 原始」Φ 在各 (f,c) 格子的行为变化 → 权重/优先级表 + 叙事
⑤ 验证（关键）：微调后 Φ_ψ 跑留出输入 → 改进特征 → 喂【真功率API，非代理】→ 对比功率真值
```



### 2.3 为什么验证用真 API 而非代理（信任的来源）

**代理只在训练期提供梯度；最终裁判是真 API 在独立留出期的功率误差。** 代理再不完美，留出验证也
会兜住——代理只需"梯度方向有用"，且该方向由 §4 抽检守住。这让整套即便代理不完美也可信。

### 2.4 三因子如何被自动吸收（这就是不手算 w 的原因）


| 手算因子             | 在 DFL 里怎么被吸收                                |
| ---------------- | ------------------------------------------- |
| value(c)（夜间=0）   | 夜间功率≈0 → `∂功率/∂特征≈0` → 梯度自然消失               |
| s(f,c) 敏感度       | 就是代理反传的 `∂ĝ/∂特征`，以梯度形式流过，不materialize       |
| reducibility 可约性 | 目标是**留出集**；upstream 修不了的白噪声硬追会过拟合→害验证→梯度不奖励 |




### 2.5 损失函数设计（时序版）

$$L(\psi)=(1-\alpha)L_{power}+\alphaL_{anchor}+\betaL_{sys\text{-}penalty}$$

- `L_power`**（真目标）**：经冻结代理的功率**序列** MSE，逐点 horizon 价值加权（夜间 `v_k≈0`）：
`L_power = (1/Σv_k) · Σ_k v_k·(ĝ(X^corr)_k − P^true_k)²`。
- `L_anchor`**（信任域 + 防作弊，推荐的第二项）**：校正后**锚定原预报**（**不是**拉向真值），逐特征
归一：`L_anchor = Σ_f (1/σ_f²)·(1/192)·Σ_k (X^corr_{f,k} − X^pred_{f,k})²`。作用——①保持在 `ĝ`
分布内（梯度才可信）；②防校正网找对抗性输入骗过 `ĝ`；③不跟功率目标在 `ε_sys` 方向打架。
- `L_sys-penalty`**（守卫）**：惩罚校正量 `Δ=X^corr−X^pred` 在**系统方向的投影**（或架构高通/只放行
事件级校正），把 `Δ` 逼进 `ε_res` 空间——"只动波动不动偏置"的落地。
- **为什么不用"指向真值的 L_weather"**：`(X^corr−X^true)²` 会驱动 `Δ→−(ε_sys+ε_res)`，顺带改被
功率模型吃掉的 `ε_sys`，既冲突又 OOD。**改进天气精度不需专门项**——功率损失自己只在"对功率有用"
（即 `ε_res` 波动）处驱动校正。仅当要把 `C_ψ` 当**通用后处理器**服务别的下游时，才加一个 `ε_res`
受限的真值项。
- **逐特征归一化** `1/σ_f²` **必需**（辐照/温度/云量量纲不同，不归一会被大量纲特征吞掉）；`α,β` 由
编排 agent 扫。`X^true` 取自 `feature_true.parquet` 的 `_true` 列，仅用于 `L_sys-penalty` 的方向
与诊断，**不进网络输入**。



### 2.6 不再需要"预先点名坏特征"

DFL 端到端：`C_ψ` **联合校正所有特征**，功率损失的梯度自动流向"改了对功率有用"的特征×时段。
**所以老 skill 的"两关点名 + 反事实定罪"前置步骤在本目标下被取代**——不必先找哪个特征有罪。

- 老 skill 的主产物（逐特征 blame）在这里**降级为事后蒸馏的副产品**：训练完看 `C_ψ` 在各 (f,c)
格子改了多少 → 得上游工单（§5 蒸馏）。**"找坏特征"从前置条件变成结果。**
- 逐特征 `ε` 分解只作为**守卫**（`L_sys-penalty` 方向）与**解释视角**存活，不再是定罪。
- 共线特征的老难题（统计分不开谁有罪）被端到端绕开——训练不需分开；仅事后蒸馏归因时才需处理。

## 3. 条件空间 c（只用于蒸馏/解释，不再用于算 w）

`c = τ(有效时刻) × h(提前期) × W(天气型) [× 季节]`，全是上游训练时也知道的坐标。

- τ 与 h 是**两个正交时间轴**，别混。
- DFL 主线里 c **不参与训练**（训练用逐点梯度）；c 只在 **④蒸馏** 和 **给人看的热力图/工单** 里用来
把连续梯度聚合成"变量×处境"的可读价目表 + 小样本闸。

---



## 4. 守卫（DFL 的可信护栏，不是 w 因子）

1. **代理共适应/OOD**：`ĝ` 继承了功率模型的共适应——在"修正系统偏差 ε_sys"方向是 OOD、最不可信。
  护栏：**把微调梯度约束在 ε_res 方向**（在分布内），并在 ε_sys 方向用**真 API 抽检**代理梯度
   （§6 抽检 agent）。这是反事实/α阶梯的唯一存活位置。
2. **代理保真度闸**：R² 不达标不训；训练中若 Φ 漂出 ĝ 拟合支撑 → 暂停、重拟合 ĝ。
3. **防遗忘**：混合 `α·L_weather`；监控天气整体保真别灾难性坍塌（有舍有得允许"无关处"退化，
  不允许全面崩）。
4. **ε_res 分解 + reducibility**：留作**诊断/护栏**（限制方向、解释、给"该不该追"打标），不进训练损失。
5. **双层/迭代**：DFL 单层已避免双层不稳；但"微调→重拟合代理→再微调"的外圈仍当迭代协同设计，限轮数、记日志。

## 5. 交付物形态

**首选（DFL 全信号）**：交「可微代理 `ĝ` + 混合损失配方（含 α 建议、ε_res 方向约束）」，上游把它加进
自己的训练图，拿到**逐点全梯度**。

**可解释/可交付（推荐并行产出）**：**先 DFL 微调副本 → 蒸馏成一张 (f,c) 权重/优先级表 + 物理叙事**。
上游即便不肯把代理塞进训练图，也能拿这张被 DFL 校准过的表乘进现有 MSE。鱼与熊掌：DFL 拿信号、
表当可讲清的产物。

**兜底（元学习）**：仅当上游是黑箱、只收"乘进现有 MSE 的标量权重"、且不肯接代理——才退回
Ren et al. 式元学习权重表（接受其粗糙与 Byrd-Lipton 风险）。

## 6. Agent 用在哪（详解）

**总原则**：梯度下降 / 代理拟合 / 蒸馏 / 指标计算都是脚本（PyTorch）的活，**LLM 一律不碰数值核**。
Agent 只做需要判断、归纳、搜索、对抗的事。四个角色 + 编排结构：

### Agent 1 — 编排 agent（AI-scientist 闭环驱动）

- **职责**：把整条 DFL 循环当状态机驱动：拟合代理→查保真→按 α 微调→留出验证→读结果→决定下一步。
- **决策点**：调 `α`（欠拟合功率则降、天气坍塌则升）、决定收敛/停、决定何时**重拟合代理**、
何时触发抽检、识别失败模式（代理保真跌、天气灾难遗忘、下游零改进）。
- **输入/输出**：只读各脚本吐的 JSON 指标；只写"下一步配置 + 决策理由"。**不算梯度。**
- **实现**：主 agent 循环；可用 `ScheduleWakeup` 跟进后台训练任务。



### Agent 2 — 归因 agent（最 LLM 对口：现象→假设）

- **职责**：读 (f,c) 敏感度/误差图 + 蒸馏权重表 + 天气型画像 → 生成**机制性、可查文献的物理假设**。
例："辐照误差集中在夏季碎云午后、提前24–48h → 对流云初生时机 → NWP 已知短板 → 建议吃卫星 nowcast X"。
- **能力**：可 `WebSearch` 查气象文献佐证"是否已知短板/是否可约"。
- **产物**：`UPSTREAM_GUIDANCE.md` 的"假设"段——把统计翻译成上游工程师能动手的叙事。接 skill
的"现象→假设→已证实"纪律：agent 提**假设**，DFL+留出验证给**已证实**。



### Agent 3 — 实验搜索 agent（agentic AutoML）

- **职责**：搜索需要判断的设计维度——`α` 调度、代理架构、`c` 分箱粒度、优先特征/格子、蒸馏形式。
- **实现**：`Workflow` 扇出候选配置 → 每个用留出下游误差评 → agent 读结果收敛。
- **纪律**：子代理禁自行放宽保真/验证阈值（沿用 skill 的 Brief I 精神）。



### Agent 4 — 抽检/对抗验证 agent（反事实的存活位）

- **职责**：编排 agent 触发；在少数高影响格子、尤其 **ε_sys（OOD）方向**，跑**真 API 的 α 阶梯**，
核对代理梯度是否可信；不可信则报"该区域回退真 API / 重拟合代理"。
- **模式**：对抗式验证——默认怀疑代理梯度，要它证明自己（对应 skill"反事实是仲裁"纪律 +
workflow 的 adversarial-verify 模式）。



### 编排结构与单写者纪律

- **主 agent**（编排 agent）调度，重活外包子代理；`Workflow` 用于 Agent 3/4 的扇出。
- **单写者**（沿用 skill）：状态/配置/`UPSTREAM_GUIDANCE.md`/权重表只由主 agent 写；子代理只读
JSON/CSV、只写自己的产物分片；**parquet 内容、payload 明细、代理权重永不进对话**。

## 7. 纪律与常见错误（复用 + 新增）

**复用 pv-feature-blame**：口径常量 import 不本地重定义；共线簇不点单个（Shapley 分份额）；小样本
只描述；物理序列重建后再跨行统计；相关≠因果。

**本方案新增**：

- ❌ 让 LLM 去算梯度/拟合/蒸馏（agent 只做判断，不碰数值核）。
- ❌ 信代理梯度不抽检——尤其 ε_sys(OOD) 方向必过真 API 抽检。
- ❌ 微调不混 `α·L_weather` → 灾难性遗忘天气泛化。
- ❌ 拿代理当最终裁判——**验证必须用真 API 在独立留出期**。
- ❌ 把 ε_res/reducibility 塞进训练损失（它们是护栏/诊断，不是 w 因子）。
- ❌ 混淆 τ 与 h 两个时间轴。
- ❌ 把"无关处天气退化"当失败（有舍有得允许；只闸全面坍塌）。

---



## 8. 验证协议（B 的唯一真检验）

- **主指标**：独立留出期，微调后 Φ 经**真功率 API** 的功率误差 vs uniform-MSE 基线（加权/不加权）。
- **消融**：α 扫描；有无 ε_res 方向约束；DFL 全梯度 vs 蒸馏权重表 vs 元学习兜底。
- **成功判据（有舍有得）**：留出集功率误差下降，且天气整体保真无灾难性坍塌——"该准处更准、可舍处放水"成立。
- **失败即承认**：无改进或遗忘坍塌 → 记录、调 α/重拟合代理/换架构，不粉饰。

---



## 9. 分期与质量闸

- **Phase 1**：可微代理 `ĝ` + 保真度闸；DFL 微调副本（单特征/小规模先跑通）+ 真 API 留出验证。
- **Phase 2**：蒸馏成 (f,c) 权重表 + 热力图/工单/可舍清单（Agent 2 归因）。
- **Phase 3**：Agent 1 编排闭环 + Agent 4 抽检 + Agent 3 配置搜索；填跨特征相干正则接口
（用户"趋势一致"愿望：高敏感格子惩罚 f1,f2 误差反号，fluctuation-consistency）。
- **Phase 4（兜底）**：元学习权重表分支。
- **质量闸**：改脚本必过 `gen_gate`（沿用 ts-diagnose）；金标准埋点——一个"代理梯度指向正确修正
方向"的格子（DFL 必学到）、一个"高误差零下游增益"（必进可舍）、一个"纯白噪声残差"（梯度不追）、
一个 ε_sys(OOD) 格子（抽检必判代理不可信）。
